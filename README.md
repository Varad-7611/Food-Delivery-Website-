# 🍔 Food Delivery Website using HTML & CSS

This project is a simple and visually appealing **Food Delivery Website** built using **HTML5** and **CSS3**.  
It provides a front-end layout that simulates a real food ordering platform with a home page, menu, order sections, and responsive design.

---

## ✨ Features

- 🏠 **Home Page** – Welcome section with promotional banners  
- 📋 **Menu Page** – Display of food categories and items with pricing  
- 🛒 **Order Now Section** – Interactive layout for selecting and ordering food  
- 📱 **Responsive Design** – Works on both mobile and desktop screens  
- 🎨 Clean and modern UI with pure HTML & CSS

---

## 🧰 Tech Stack

- **HTML5**
- **CSS3**
